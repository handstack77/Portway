# WinSCP 고급 기능 대체 검증표

버전 0.3.6, 2026-09-29. **전체 기능 동등성은 아직 달성하지 못했습니다.** 아래 표는 구현과 검증을 분리한 현재 인수 기준입니다. 라이브러리가 설정을 노출한다는 이유만으로 상호 운용 검증 완료로 표시하지 않습니다. 기존 프로토콜·드롭 검증은 0.3.1 보고서, 자동 업데이트는 0.3.3, Monaco는 0.3.4, 다중 선택·파일 관리 UI는 0.3.5 보고서를 기준으로 합니다.

기준 문서: [기능 개요](https://winscp.net/eng/docs/introduction), [고급 연결 설정](https://winscp.net/eng/docs/ui_login_advanced), [전송 설정](https://winscp.net/eng/docs/transfer_settings), [스크립트](https://winscp.net/eng/docs/scripting), [파일 암호화 형식](https://winscp.net/eng/docs/file_encryption).

| 기능 | 구현 / 검증 상태 | 증거 또는 남은 범위 |
|---|---|---|
| SFTP, SCP, FTP, WebDAV, S3 | 구현, 실제 서버 왕복 검증 | `ProtocolTests`의 바이트 비교, 특수 이름, 이동/삭제/동기화 |
| FTPS, HTTPS 인증서 핀 | 구현, 자체 서명 TLS 서버 검증 | 잘못된/미신뢰 인증서 거부 및 정확한 핀 성공 |
| SSH 키, PPK, OpenSSH Agent | 구현, 실제 인증 검증 | `AdvancedProtocolTests`; PPK 변환 없이 직접 읽기 |
| MFA / keyboard-interactive | 구현, PAM 대화형 인증 검증 | 실제 외부 OTP 공급자마다 추가 검증 필요 |
| HTTP, SOCKS4/5 프록시 | 구현, SSH 검증 | FTP/WebDAV 프록시 조합별 검증 남음 |
| 단일 SSH 점프 | 구현, 양쪽 호스트 키 검증 | 여러 단계 점프와 비SSH 프로토콜 터널 없음 |
| Pageant / SSH 사용자 인증서 | 설정 및 구현 | 실제 Pageant/CA 서명 인증서 검사 남음 |
| TLS 클라이언트 인증서 | PFX/P12 구현 | 상호 TLS 서버 검증 남음; 인증서 조회는 직접 연결 |
| GSSAPI/Kerberos, SSH agent forwarding | 미구현 | SSH.NET 기본 인증 범위 밖의 별도 인증/채널 구현 필요 |
| 암호·키 암호·토큰·프록시 암호 Vault | 구현, 암호화/잠금/대상 바인딩 검증 | 새 파일 암호화 키도 동일 Vault에 저장. 재실행 후 자동 잠금 해제는 Windows DPAPI에서 검증했으며 macOS 키체인·Linux Secret Service 실제 OS 검증은 남음 |
| WinSCP SFTP 파일 암호화 | 구현, 공식 WinSCP 6.5.7 양방향 교차 검증 | 기존 평문 파일 정책, 새 파일/폴더 이름 암호화; 암호화 파일은 부분 재개 대신 재전송 |
| 전송 큐 영속화·재개 | 구현, 앱 서비스 재생성 검증 | 잠금 해제 후 같은 부분 파일로 재개. OS 강제 종료/정전 전체 조합은 미검증 |
| 동시 실행·우선순위·예약·재시도 | 구현 | 동시 1–8, 우선순위 -10–10, 시각 예약, 일시 네트워크 오류 재시도 |
| 속도 제한·전송 프리셋·필터 | 구현, 필터/속도 중단 검증 | WinSCP 마스크의 모든 이스케이프/상대 시간 문법은 미지원 |
| 텍스트 모드·줄바꿈·대소문자·이동 | 구현, 실제 전송 검증 | 자동 마스크 및 LF/CRLF, SHA256, 새 파일만, 숨김/빈 폴더 제외 |
| 수정 시각·권한·UID/GID | 구현 | SFTP/SCP 권한 보존 검증, FTP MFMT 제공 여부에 따름; ACL/xattr 전반 없음 |
| 미리보기 동기화·부분 선택·충돌 방향 | 구현, 동일 크기/시각 변경 거부 검증 | 최대 20,000항목, 깊이 64; 전체 폴더 롤백 없음 |
| 지속 동기화 | 구현, 변경 감지/일시정지/재시작 검증 | 단방향, 파일 감시+주기 비교; 등록은 복원되지만 자동 재개하지 않음 |
| 내부 편집기 | Monaco 구현, Chromium/WebKit·실제 SFTP 편집 저장 검증 | 구문 강조·찾기/바꾸기·언어 선택·줄바꿈, 16MiB, UTF8/16/32 BOM·cp949. 로컬/원격 해시 충돌 검사, 저장 중 추가 입력 보존 |
| 외부 편집기 자동 업로드 | 구현, 저장/동시 수정/덮어쓰기 검증 | 임의 실행 파일+인수 배열. 복구 사본을 자동 삭제하지 않음 |
| PTY 터미널 | 구현, 서버 및 브라우저 검증 | 입력, 창 크기, Ctrl+C, xterm.js 화면. 암호화 경로는 별도 일반 SSH 연결 필요 |
| 원격 검색·체크섬·폴더 크기·복사 | 구현, 실제 SFTP 검증 | S3/WebDAV는 서버 복사, 나머지는 다운로드/업로드 검증 |
| 심볼릭 링크 생성/이동/삭제 | 구현, SFTP 정상/깨진 링크 검증 | 링크 대상을 삭제하지 않음. 재귀 전송/동기화에서 링크 추적은 미지원 |
| 휴지통·복원 | 구현, 로컬/원격 복원 검증 | 같은 부모 `.portway-trash`; OS 고유 휴지통과 별개, 원위치 충돌 시 거부 |
| S3 세션 토큰·경로 주소·스토리지 클래스 | 구현 | 기본 S3 호환 서버 검증. AWS IAM/STS, Requester Pays 과금, >5GiB 복사는 별도 검증 필요 |
| WinSCP INI 가져오기 | 구현 | 암호·레지스트리·전체 작업 공간·PuTTY 세션 전체 이전 미지원 |
| CLI/.NET 자동화 | 구현, 실제 스크립트 검증 | `AUTOMATION.md`에 지원 문법 명시. WinSCPnet.dll/COM 및 모든 스크립트 호환 아님 |
| 사용자 명령 | 구현, 경로 인용 검증 | 저장된 SSH 템플릿 실행. WinSCP 확장 스크립트 설치/전체 매크로 문법 미지원 |
| 패널 다중 선택·컨텍스트 메뉴·단축키 | 박스·체크박스·범위·반전 선택, Chromium/WebKit 검증 | SFTP 다중 업로드·다운로드·이동, 파일별 체크섬, 일괄 권한·휴지통, 부분 삭제 실패. OS 고유 셸 동작 전체 호환은 아님 |
| 외부 파일 관리자 → 앱 드롭 | 구현, Windows Chromium 실제 파일 경로 드롭 및 실제 SFTP 전송 검증 | 파일·중첩/빈 폴더·한글·100개 초과 항목·다중 청크·취소. 실제 Explorer/Finder/WebKitGTK OS 드래그 제스처는 별도 실기기 검증 필요 |
| Tabler / Icons 웹 폰트 / Master CSS | 구현, 앱·배포 센터 라이트/다크 화면 검증 | 정적 로컬 자산, 영구 테마·시스템 변경 추적, 980×680 레이아웃 |
| 기타 Explorer/Finder 통합 | 미구현 | 앱 → 파일 관리자 드래그아웃, 셸 확장, URL 핸들러, 점프 목록, 자동 작업 공간 복원 필요 |
| VPK 배포/업데이트 서버 | 구현 | 실제 패키지 게시/해시/Range 테스트; 검증 결과는 `doc/Portway.Document/jobs/VALIDATION.md` |
| 시작 시 자동 확인·다운로드 / 다음 시작 시 무인 적용 | 구현, Windows 격리 설치 검증 | 실행 중 버전 유지, 오프라인 다음 시작 적용, 설정 보존, 수동 업데이트 회귀 통과. macOS/Linux 실제 무인 업데이트는 미검증 |
| macOS·ARM64 실기기 | 환경 필요 | 원격 Mac/CI 저장소와 서명 자격 증명 미제공. 교차 빌드는 실제 실행 검증이 아님 |

다음 완료 단계는 미구현 기능을 추가한 뒤 해당 서버·운영체제의 상호 운용 테스트를 추가하는 것입니다. 특히 GSS/Kerberos, COM/기존 스크립트 호환, OS 통합, macOS 실기기 설치·업데이트를 통과하기 전에는 WinSCP의 완전한 대체품으로 표시할 수 없습니다.
