# 0.3.5 — 파일 탐색기 다중 선택과 작업 메뉴

검증일: 2026-09-29 (KST). Windows x64에서 소스·게시 실행 파일의 loopback 호스트와 Playwright CLI의 Chromium/WebKit을 사용했습니다. 파일 작업은 실제 로컬 디스크와 격리된 Docker SFTP 서버에서 수행했습니다.

## 변경 내용

- 로컬·원격 패널의 체크박스, 전체 선택·선택 반전, Ctrl/Cmd 추가 선택, Shift 범위 선택을 제공합니다. 선택 개수와 파일·폴더 구분, 빠른 전송·휴지통 버튼을 표시합니다.
- 빈 공간·크기·날짜 영역의 박스 선택, 가장자리 자동 스크롤, 드래그 중 Esc 취소를 지원합니다. Ctrl/Cmd 박스 반전은 시작 시 선택을 기준으로 계산합니다.
- 파일 이름을 끌면 선택한 항목을 함께 전송하고, 반대 패널의 실제 폴더 위에 놓으면 해당 폴더를 목적지로 지정합니다. 세션과 경로를 캡처하며 외부 MIME JSON을 경로로 신뢰하지 않습니다.
- 우클릭/Shift+F10/… 작업 메뉴는 선택을 유지하고 지원 조건에 따라 항목을 비활성화합니다. 키보드로 메뉴를 탐색하고 닫을 수 있습니다.
- F5 전송, F6 이동, Delete 휴지통, Shift+Delete 확인 후 영구 삭제, Ctrl/Cmd+L/F/R, 경로 복사, 선택 정보, Tab 패널 전환, Home/End/Page/Insert/Space와 범위 선택을 제공합니다.
- 여러 파일의 SHA256 결과와 여러 원격 항목의 권한·소유자 변경을 지원합니다. 휴지통·권한·영구 삭제가 일부 성공 후 실패하면 완료 개수와 오류를 표시하고 목록을 갱신합니다. 전체 롤백은 제공하지 않습니다.
- 패널별 정렬, 정렬·같은 폴더 새로고침 시 경로 기반 선택 유지, 필터에 가려진 선택 해제, 폴더·세션 변경 시 초기화와 오래된 목록 응답 무시를 구현했습니다.
- 고정 헤더 아래에 키보드 커서를 표시하고 Tabler 테이블 여백을 정리했습니다. 전송 큐 접기와 선택 도움말 버튼을 추가하고 두 테마를 적용했습니다.
- 사용자·개발자 가이드와 AGENTS.md에 선택 및 작업 계약을 기록했습니다. 기존 Monaco와 외부 파일 드롭을 유지합니다.

## 검증 범위

Windows 호스트의 Chromium/WebKit 검증이며, 실제 macOS/Linux Photino WebView나 Explorer/Finder 네이티브 드래그 제스처를 검증한 것은 아닙니다. 터치·네이티브 IME·스크린 리더의 실제 동작도 이번 범위에 포함하지 않았습니다. 전체 프로토콜 회귀는 반복하지 않았습니다.

Windows 패키지는 서명되지 않았고 공개 서버에 배포하지 않았습니다. 설치·무인 업데이트·제거 검증은 이번에 반복하지 않았으며 [0.3.3 기록](VALIDATION-0.3.3.md)을 참고하세요. Linux AppImage는 기존 0.3.1이며 새 UI는 해당 OS에서 현재 소스를 다시 패키징해야 합니다. WinSCP의 전체 기능 동등성을 뜻하지 않습니다.

QA용 브라우저·호스트·격리 SFTP 컨테이너는 종료했습니다. 입력과 로그는 artifacts/qa/에 남겼습니다.
